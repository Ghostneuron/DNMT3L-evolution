# License selection required

No public-use license has been selected for this release candidate. Do not publish the repository or Zenodo record until the author chooses and adds the intended license terms.

A common option for a mixed code-and-data research repository is:

- MIT License for files under `scripts/`
- Creative Commons Attribution 4.0 International (CC BY 4.0) for data, figures, documentation, and other non-code material

Another option is a single license that the author confirms is appropriate for every original component. Third-party source records remain subject to their original database or resource terms regardless of the repository license.

After choosing:

1. Add the complete license text or texts at the package root.
2. State clearly which files each license covers.
3. Add the selected SPDX license identifier to `CITATION.cff`.
4. Add the corresponding Zenodo license identifier to `.zenodo.json` and the Zenodo deposit form.
5. Rebuild the package manifest, checksums, and ZIP archives.
